# Zorvus

Zorvus is an undetectable AI copilot that reads, listens, and supports every decision in real time. It works silently in the background, helping you stay focused while providing context-aware assistance.

## Features

### Core Intelligence
- **Real-Time Assistance**: Instant AI guidance that monitors your screen and environment without interruptions.
- **Smart Meeting Prep**: Background information on attendees and relevant documents before calls.
- **Live Contextual Guidance**: Recognizes ongoing activities and provides relevant prompts.
- **Completely Invisible**: Works seamlessly across Zoom, Teams, Webex, and more without appearing on shared screens.

### Productivity Features
- **Automatic Summaries**: Notes, follow-up emails, and action items generated automatically.
- **Knowledge Hub**: Centralized prompts and resources for quick access.
- **Usage Analytics**: Track feature usage and identify gaps.
- **Custom Hotkeys**: Personalized keyboard shortcuts for instant control.
- **Draggable Window**: Place the AI assistant anywhere on your screen.
- **Screenshot Analysis**: Understands context from screen content.

### Privacy & Security
- End-to-end encryption
- Isolated workspaces
- Strict access controls
- No digital footprint
